# Chapter pages

One Markdown page per chapter, for the people who draw the artwork.

```
npm run content:md
```

**These files are generated. Never edit one by hand** — edit the chapter in `content/<class>/` and run the command again.

Each page carries what someone needs in front of them to draw a panel sequence, which otherwise lives in four places at once:

1. the story, beat by beat, as the app tells it today
2. the Memory Verse, exact, with its reference
3. the lesson's own questions, each with what the child must take away and the answer quoted from the printed page
4. My Decision, the song, the prayer, and the chapter's own closing line
5. every game the chapter already has — and, for each, **the words a shelf card must never letter**, because artwork is reused as game cards
6. what the artwork has to carry, from the curriculum's own objectives
7. whatever the build recorded about the chapter: missing pages, printing errors, editorial questions left for the teacher

Two honesty rules each page states for itself. The verse, the questions, the decision, the song and the prayers are **verbatim** from the curriculum. The story is the **app's child-facing telling**, not the printed lesson's own prose — nothing here re-transcribes a page, it re-presents what was already read from one.

The curriculum photographs in Drive remain the source of truth. A page that disagrees with them is a bug in the chapter, not in this folder.
